📖 Cara Memasang README ke Profil GitHub

        
      


      

        
1

        

          
Buat Repository Khusus di GitHub

          
Buka github.com/new. Isi nama repository SAMA PERSIS dengan Username GitHub kamu.

        

      


      

        
2

        

          
Atur Akses ke Public & Tambah README

          
Pastikan opsi ditandai sebagai Public, lalu beri centang pada Add a README file.

        

      


      

        
3

        

          
Copy Kode dari Generator Ini

          
Gunakan tombol 📋 Copy Kode atau 💾 Download .md yang ada di generator ini.

        

      


      

        
4

        

          
Edit & Paste di GitHub Editor

          
Buka repo kamu (github.com/username/username), klik Edit README.md, lalu paste kodenya.

        

      


      

        
5

        

          
Commit Changes

          
Klik tombol hijau Commit changes... di pojok kanan atas.
